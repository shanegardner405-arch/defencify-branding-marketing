Production asset note

These scenes are directional review assets for composition, buyer context, and uniform treatment only. Final website use should move through Defencify approval and default to approved production photography unless Adam, John, and Clementina explicitly approve final generated assets for this surface.

Prompt rules

Generate believable security operations, not brand-pasted mockups.

  1. Do not generate new Defencify logos, patches, badges, seals, wordmarks, or fake brand marks unless the session task is explicitly logo exploration.
  2. Use real workplace settings: lobby desk, patrol briefing, incident report station, loading dock, control room, campus entrance.
  3. Show security guards and operations managers working, reviewing, coaching, checking in, or reporting.
  4. Avoid military styling, tactical fantasy, dark surveillance rooms, exaggerated uniforms, and generic classroom stock.
