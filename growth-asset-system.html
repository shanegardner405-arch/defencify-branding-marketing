08

Prompting model

Prompts are production briefs, not one-off requests. Each one carries source rules, subject, setting, composition, and rejection criteria.

Brand context

Paste logo rules, colors, type, icon style, imagery standards, tone, and what must not appear.

Subject

Name the asset, audience, course family, scene, role, action, and intended channel.

Environment

Define light, location, realism, camera distance, and professional security context.

Composition

State crop, whitespace, text zone, hierarchy, and how the output will be used inside a layout.

09

Why this scales

The framework keeps identity fixed while allowing audience, channel, message, CTA, and course context to vary.

Customizability

One approved system can target different states, courses, personas, and campaign stages without rebuilding the identity.

Productivity

The team starts from approved templates, source traces, and reusable prompts instead of blank canvases.

Scalability

Once approved, the system can generate channel-ready variants for courses, documentation, sales, and marketing.
